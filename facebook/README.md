# Facebook Scraper - Pages, Reels, Photos, Events

Public Facebook pages, reels, photos, events and reel transcripts.

- API page: https://rapidapi.com/unseenuser/api/facebook-data-api5
- Tutorials: https://rapidapi.com/unseenuser/api/facebook-data-api5/tutorials
- Playground: https://rapidapi.com/unseenuser/api/facebook-data-api5/playground

## Examples in this folder

- [`01_get_facebook_page_photos_and_reels_with_python.py`](01_get_facebook_page_photos_and_reels_with_python.py) - Get Facebook page photos and reels with Python
- [`curl.sh`](curl.sh) - First call with curl
- [`02_download_a_facebook_page_s_reels_as_mp4_files_pyth.py`](02_download_a_facebook_page_s_reels_as_mp4_files_pyth.py) - Download a Facebook page's reels as MP4 files (Python)
- [`03_find_events_in_a_city_and_export_them_to_csv_pytho.py`](03_find_events_in_a_city_and_export_them_to_csv_pytho.py) - Find events in a city and export them to CSV (Python)

Full step-by-step guides are on the [Tutorials tab](https://rapidapi.com/unseenuser/api/facebook-data-api5/tutorials).
