# Meta Ad Library - Facebook & Instagram Ads

Search Facebook and Instagram ads from the Meta Ad Library by keyword.

- API page: https://rapidapi.com/unseenuser/api/meta-ad-library-api1
- Tutorials: https://rapidapi.com/unseenuser/api/meta-ad-library-api1/tutorials
- Playground: https://rapidapi.com/unseenuser/api/meta-ad-library-api1/playground
