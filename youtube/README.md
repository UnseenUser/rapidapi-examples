# YouTube Scraper - Channels, Videos, Comments, No Quota

Channels, videos, comments, shorts, playlists and search without a YouTube API key.

- API page: https://rapidapi.com/unseenuser/api/youtube-data-api28
- Tutorials: https://rapidapi.com/unseenuser/api/youtube-data-api28/tutorials
- Playground: https://rapidapi.com/unseenuser/api/youtube-data-api28/playground

## Examples in this folder

- [`01_get_youtube_channel_stats_and_latest_videos_with_p.py`](01_get_youtube_channel_stats_and_latest_videos_with_p.py) - Get YouTube channel stats and latest videos with Python
- [`curl.sh`](curl.sh) - First call with curl
- [`02_compare_youtube_channels_and_export_their_latest_v.py`](02_compare_youtube_channels_and_export_their_latest_v.py) - Compare YouTube channels and export their latest videos to CSV (Python)
- [`03_collect_youtube_comments_for_sentiment_analysis_py.py`](03_collect_youtube_comments_for_sentiment_analysis_py.py) - Collect YouTube comments for sentiment analysis (Python)

Full step-by-step guides are on the [Tutorials tab](https://rapidapi.com/unseenuser/api/youtube-data-api28/tutorials).
