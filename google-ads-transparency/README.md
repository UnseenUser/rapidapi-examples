# Google Ads Transparency - Competitor Ads

Pull any advertiser's Google ads (Search, YouTube, Display) by website.

- API page: https://rapidapi.com/unseenuser/api/google-ads-transparency-api5
- Tutorials: https://rapidapi.com/unseenuser/api/google-ads-transparency-api5/tutorials
- Playground: https://rapidapi.com/unseenuser/api/google-ads-transparency-api5/playground

## Examples in this folder

- [`01_get_a_brand_s_google_ads_by_website_with_python.py`](01_get_a_brand_s_google_ads_by_website_with_python.py) - Get a brand's Google ads by website with Python
- [`curl.sh`](curl.sh) - First call with curl
- [`02_compare_competitors_google_ads_side_by_side_in_a_c.py`](02_compare_competitors_google_ads_side_by_side_in_a_c.py) - Compare competitors' Google ads side by side in a CSV (Python)
- [`03_google_ads_transparency_api_with_node_js_javascrip.mjs`](03_google_ads_transparency_api_with_node_js_javascrip.mjs) - Google Ads Transparency API with Node.js (JavaScript quick start)

Full step-by-step guides are on the [Tutorials tab](https://rapidapi.com/unseenuser/api/google-ads-transparency-api5/tutorials).
